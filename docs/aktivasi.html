Pengaturan satu kali

Hubungkan, lalu cukup menulis.

Blog Anda tetap di GitHub Pages. Layanan kecil di Cloudflare menghubungkan tombol Terbitkan ke repository dengan login GitHub.

1. Buat layanan penerbitan

Masuk atau buat akun di Cloudflare. Buat Worker bernama ruang-tulis-publisher, lalu masukkan kode yang sudah disiapkan di publisher/worker.bundle.mjs.

2. Aktifkan penyimpanan sesi

Buat namespace KV, lalu hubungkan ke Worker dengan nama binding SESSIONS. Penyimpanan ini hanya untuk sesi login; draft tetap berada di perangkat Anda.

3. Daftarkan login GitHub

Buat OAuth App GitHub. Homepage menggunakan alamat blog Anda, sedangkan callback menggunakan alamat Worker diikuti /auth/callback. Masukkan Client ID, Client Secret, dan kunci sesi langsung ke pengaturan Cloudflare.

4. Hubungkan ke blog

Isi alamat Worker pada publisherUrl di konfigurasi website. Sesudah perubahan tersedia di GitHub Pages, buka editor dan pilih Hubungkan GitHub.

Draft Anda tetap bisa digunakan sekarang.Aktivasi ini diperlukan untuk menerbitkan, bukan untuk mulai menulis. Jangan kirimkan Client Secret atau kunci sesi melalui chat.
